
# Embedded ECG Monitoring System

## Présentation du projet

Conception d'un système embarqué destiné à
l'acquisition, au traitement et à la visualisation
des signaux électrocardiographiques (ECG).

Le projet repose sur l'intégration d'un capteur ECG
et d'un microcontrôleur, ainsi que sur des techniques
de conditionnement et de filtrage du signal.

## Objectifs

- Acquérir les signaux électriques cardiaques.
- Interfacer le capteur avec un microcontrôleur.
- Réaliser le conditionnement du signal.
- Atténuer les perturbations et le bruit.
- Afficher les signaux acquis.

## Réalisations techniques

- Interfaçage du capteur ECG.
- Acquisition des données du capteur.
- Conditionnement des signaux électriques.
- Application de techniques de filtrage.
- Traitement des données acquises.
- Visualisation des signaux cardiaques.
