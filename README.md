# Embedded-ECG-Monitoring
Conception d'un système embarqué d'acquisition et de surveillance électrocardiographique (ECG). Interfaçage d'un capteur biomédical avec un microcontrôleur, acquisition des signaux cardiaques, conditionnement, filtrage des perturbations et affichage. Application des techniques d'instrumentation électronique et de traitement numérique du signal.
